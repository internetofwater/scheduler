Geoconnex is a data product from the Internet of Water Coalition, maintained by the US Geological Survey and the Lincoln Institute of Land Policy's Center for Geospatial Solutions. It aims to link vector hydrologic features across the United States such as water monitoring locations, Hydrologic Unit Codes (HUCs), or administrative boundaries for public water supplies. It also includes their associated datasets.

This catalog contains GeoParquet and PMTiles for each sitemap in the Geoconnex registry and listed in the sitemap here: https://geoconnex.us/sitemap.xml
The GeoParquet files contain a `jsonld` column which can be used for reconstructing the RDF graph database. For columnar analytics, this column can be ignored.

For more info see the docs here: https://docs.geoconnex.us/
